타비니혼고 — 일본 여행 일본어 앱

포함 기능
- 하루 15분 학습 화면, 메뉴·간판 단어 도감
- 일본어 발음 음성 재생(기기/브라우저의 일본어 음성 지원에 따라 다름)
- 미니 퀴즈, 익힌 단어/복습 목록/최고 점수 저장
- 사진 촬영 또는 사진 선택 후 일본어 OCR(첫 실행 시 인터넷 연결 필요)
- 홈 화면 설치를 위한 PWA manifest 및 서비스 워커

중요한 제한
이 압축 파일만 휴대폰에서 열면 홈 화면 앱 설치가 완성되는 것은 아닙니다. Android의 홈 화면 설치는 HTTPS 주소에서 제공되는 웹앱을 통해 하는 것이 가장 쉽습니다. 아래 배포 방법으로 개인 웹 주소를 만든 뒤 Chrome에서 열어 설치하세요.
OCR은 Tesseract.js와 일본어 언어 데이터를 온라인에서 가져옵니다. 오프라인에서는 사진 OCR이 작동하지 않을 수 있습니다. 학습 진도는 해당 기기/브라우저의 로컬 저장소에 보관되며, 브라우저 데이터를 삭제하면 사라집니다.

쉬운 배포 방법(무료 호스팅 서비스 예: GitHub Pages)
1. PC에서 GitHub 계정에 로그인하고 새 공개 저장소를 만듭니다.
2. 압축을 풀어 index.html, manifest.webmanifest, sw.js 파일을 저장소 최상위에 업로드합니다.
3. 저장소 Settings → Pages → Deploy from a branch → main / root를 선택해 저장합니다.
4. 생성된 https://계정이름.github.io/저장소이름/ 주소를 Android Chrome에서 엽니다.
5. Chrome 메뉴(⋮) → '홈 화면에 추가' 또는 '앱 설치'를 누릅니다.
6. 설치 후 홈 화면의 타비니혼고 아이콘으로 실행합니다. ChatGPT를 열 필요가 없습니다.

파일을 수정할 때는 저장소의 해당 파일을 교체하면 됩니다.


J-POP 가사 학습장
- 곡 상세 화면에서 일본어 가사 검색 링크를 열 수 있습니다.
- 사용 권한이 있는 가사 또는 사용자가 제공한 텍스트를 붙여 넣고 줄별 학습장을 만들 수 있습니다.
- 각 줄에 히라가나 읽기와 한국어 뜻을 입력하고, 지원되는 환경에서는 줄별 자동 번역을 시도할 수 있습니다.
- 학습 내용은 같은 브라우저의 로컬 저장소에 저장됩니다.
- 자동 번역은 외부 번역 서비스 연결에 의존하며, 결과를 검토해야 합니다. 한자 독음은 자동 생성되지 않으므로 직접 확인해야 합니다.
